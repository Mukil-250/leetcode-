# Zoro Shop Co. – Product Cards

This is a mini project I made for my Web Designing Lab. It's a simple product listing page for a stationery shop, built using just HTML and CSS (no frameworks, no JavaScript libraries, nothing fancy).

The idea was to practice building product cards like you'd see on a real e-commerce site — stuff like notebooks, pens, and desk organizers, with sale tags, discount badges, and a "Buy Now" button on each one.

## What's on the page

- A grid of 6 product cards that wrap nicely depending on screen size
- A red "SALE" ribbon on items that are discounted
- Old price shown with a strikethrough next to the new price
- A little badge under each product (like "Best Seller", "New Arrival", or the discount %)
- Cards lift up slightly and the image zooms in a bit when you hover over them
- A green "Buy Now" button on every card

## Built with

Just plain HTML and CSS. That's it. No React, no Bootstrap, no dependencies to install.

## How to run it

You don't need to set anything up. Just download or clone the repo and open `product-cards.html` in any browser.

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
```

Then double-click the HTML file, or open it in your browser manually.
